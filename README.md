# 🕹️ Glass Arcade

Коллекция из шести классических мини-игр в стиле **iOS Liquid Glass**: настоящее преломление через SVG-displacement, переливающийся aurora-фон, 3D-tilt карточек, стеклянные панели с бликами. Чистый HTML / CSS / JS — без сборки, без зависимостей.

**Игры:** Змейка · Тетрис · 2048 · Арканоид · Светлячок (flappy) · Память

- 📱 Телефон: свайпы, тапы, экранные кнопки
- 💻 ПК: клавиатура (стрелки / WASD / пробел), мышь, hover-эффекты
- 🏆 Рекорды сохраняются на устройстве (localStorage)
- ♿ Поддержка `prefers-reduced-motion`, фокус с клавиатуры, Esc — закрыть, P — пауза

## Запуск локально

Просто откройте `index.html` в браузере. Всё.

## Деплой на GitHub Pages

### Способ 1 — одной командой (Python)

Откройте **`token.txt`**, впишите туда две строки — ваш логин и **новый** токен — и запустите:

```bash
python3 deploy.py
```

На Windows можно просто запустить файл двойным кликом или из IDLE. Нужен только Python 3.10+ — **git не требуется**, файлы заливаются напрямую через GitHub API. Токен можно также передать через окружение (`GH_USER=... GH_TOKEN=...`) или ввести интерактивно.

Скрипт создаст репозиторий, загрузит файлы и включит Pages. `token.txt` и сами deploy-скрипты в публикацию не попадают никогда — они жёстко исключены из списка загрузки.

Альтернатива на bash (требует git) — `./deploy.sh`.

> ⚠️ Используйте **новый** токен. Если ваш токен когда-либо попадал в чат,
> переписку или скриншот — отзовите его: GitHub → Settings →
> Developer settings → Personal access tokens → Revoke.

Нужные права fine-grained токена: **Contents** (Read/Write), **Pages** (Read/Write), **Administration** (Read/Write — для создания репозитория).

### Способ 2 — вручную через сайт GitHub

1. Создайте новый репозиторий, например `glass-arcade`
2. Загрузите все файлы проекта, кроме `token.txt` (кнопка *uploading an existing file*)
3. Settings → Pages → Source: **Deploy from a branch** → `main` → `/ (root)`
4. Сайт появится по адресу `https://ваш_логин.github.io/glass-arcade/`

(Если предпочитаете сборку через Actions — в архиве есть `.github/workflows/deploy.yml`, тогда в шаге 3 выберите Source: GitHub Actions.)

## Структура

```
index.html              — разметка, SVG-фильтры преломления
css/style.css           — дизайн-система Liquid Glass
js/main.js              — реестр игр, модальный лист, общий Game API
js/games/*.js           — шесть игр, каждая в своём файле
.github/workflows/      — автодеплой на Pages
deploy.py               — деплой одной командой (Python)
token.txt               — сюда вписать логин и токен (в .gitignore)
deploy.sh               — то же на bash
```
